# Manual checklist

What automation cannot prove: the real payment environment, a real screen reader, other browsers. Run on the live site (<https://moringa-silk.vercel.app>) before each release. Fill in the result, the date and a link to the evidence (screenshot or video).

| ID    | Check                  | Steps                                                                                                                                                                  | Expected                                                                                                                                           | Result |
| ----- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| MC-01 | Card payment           | Add a piece, check out with `4242 4242 4242 4242`, any future date and CVC                                                                                             | Stripe test page with the same total as the pay button; back on Moringa, the confirmation with the order code; the order in "Meus pedidos" as Paid | ⏳     |
| MC-02 | Declined card          | Same, with `4000 0000 0000 0002`                                                                                                                                       | Stripe says the card was declined; back on Moringa, the bag is still there                                                                         | ⏳     |
| MC-03 | Pix (test mode)        | Choose Pix on the Stripe page                                                                                                                                          | Stripe shows the test QR code; the order stays Pending until Stripe confirms                                                                       | ⏳     |
| MC-04 | Screen reader          | Windows + [NVDA](https://www.nvaccess.org/download/) + Chrome, eyes off the screen: find a piece by region, add to the bag, open the checkout, read the order timeline | Every control has a clear name; the bag count and form errors are announced; the timeline is read in order with dates                              | ⏳     |
| MC-05 | Zoom and high contrast | Browser zoom 200%; then Windows "Contrast themes"                                                                                                                      | Nothing cut or overlapping at 200%; borders, focus and status still visible in high contrast                                                       | ⏳     |
| MC-06 | Other browsers         | Firefox, and Safari on an iPhone (or a Mac)                                                                                                                            | Same journey as MC-01 works; theme and language switches work                                                                                      | ⏳     |
| MC-07 | Maker on a phone       | On a phone, enter as Dona Lúcia, ship an order with code `BR123456789BR`                                                                                               | The order leaves "To ship"; as Marina, the code shows in the timeline                                                                              | ⏳     |

**How to report what fails:** open an issue with the [bug template](../../.github/ISSUE_TEMPLATE/bug_report.yml) and put its number in the Result column.
