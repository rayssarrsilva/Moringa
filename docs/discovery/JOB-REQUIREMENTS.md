# Job requirements map

Moringa is built to cover what real **junior frontend (React + Next.js)** job posts ask for. Each row points to where the requirement lives in this project. The links will be filled in as the code is written.

| What job posts ask for                       | Where it is in Moringa                                                                                                                                                                                                                                  | Status |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Semantic HTML, CSS3, responsive layout       | Every screen, mobile first; landmarks, headings, `dl` and breadcrumbs · [catalog page](../../src/app/%5Blocale%5D/pecas/page.tsx)                                                                                                                       | 🚧     |
| Modern JavaScript and TypeScript             | The whole codebase, strict TypeScript · [strict `tsconfig.json`](../../tsconfig.json)                                                                                                                                                                   | 🚧     |
| React, hooks, reusable components            | Server and Client Components on the Ipê Design System · [`src/components`](../../src/components)                                                                                                                                                        | 🚧     |
| Next.js App Router                           | Server Components, `generateStaticParams`, ISR (`revalidate`), `generateMetadata`, route handlers · [`src/app/[locale]`](../../src/app/%5Blocale%5D)                                                                                                    | 🚧     |
| Consuming REST APIs                          | Own catalog API · [`/api/pieces`](../../src/app/api/pieces/route.ts); public ViaCEP API with abort and error states · [`viacep.ts`](../../src/lib/checkout/viacep.ts)                                                                                   | ✅     |
| State management (Redux, Zustand or similar) | Zustand bag persisted in localStorage, written test-first · [`src/lib/bag`](../../src/lib/bag); TanStack Query with server prefetch, polling and optimistic updates in the buyer area · [`order-view.tsx`](../../src/components/account/order-view.tsx) | ✅     |
| Forms and validation                         | React Hook Form + Zod, one schema shared by browser and server action · [`checkout-form.tsx`](../../src/components/bag/checkout-form.tsx)                                                                                                               | 🚧     |
| Jest and React Testing Library               | Vitest + React Testing Library (Jest-compatible API), TDD on the bag; integration tests on a real Postgres (PGlite) that check the SQL against the in-memory rules · [`src/db/integration.test.ts`](../../src/db/integration.test.ts)                   | ✅     |
| Cypress or similar E2E                       | Playwright, with buyer and seller sessions in the same test · [`e2e/`](../../e2e/home.spec.ts)                                                                                                                                                          | 🚧     |
| Git, branches and pull requests              | PR template, Conventional Commits, code review on every change · [PR template](../../.github/pull_request_template.md), commitlint                                                                                                                      | 🚧     |
| Agile, sprints                               | GitHub Projects board, issues from the [backlog](./BACKLOG.md), one-week sprints · [Project board](https://github.com/users/rayssarrsilva/projects/4)                                                                                                   | 🚧     |
| CI/CD                                        | GitHub Actions and Vercel preview deploys on every pull request · [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)                                                                                                                          | 🚧     |
| Authentication                               | Auth.js v5 (NextAuth) with JWT sessions, protected pages and API routes, one-click demo login · [`src/auth.ts`](../../src/auth.ts)                                                                                                                      | 🚧     |
| Nice to have: e-commerce                     | Bag, CEP lookup, Stripe Checkout in test mode (card and Pix), webhook with signature check, one order per maker · [`finalizar/actions.ts`](../../src/app/%5Blocale%5D/finalizar/actions.ts)                                                             | 🚧     |
| Nice to have: SEO                            | Metadata with hreflang, Open Graph images per piece and shop, sitemap, robots, Product and BreadcrumbList JSON-LD · [`src/lib/seo.ts`](../../src/lib/seo.ts)                                                                                            | ✅     |
| Nice to have: accessibility                  | WCAG 2.2 AA, axe on every page in Playwright · [`e2e/catalog.spec.ts`](../../e2e/catalog.spec.ts)                                                                                                                                                       | 🚧     |
| Nice to have: Core Web Vitals                | Lighthouse CI budget on every pull request                                                                                                                                                                                                              | ⏳     |

| Nice to have: i18n                           | next-intl, `/pt` and `/en` routes · [`messages/`](../../messages) and [`src/i18n`](../../src/i18n)                                                                                                                                                      | 🚧     |
| Nice to have: Node.js                        | Server Actions, route handlers and the Stripe webhook · [`api/stripe/webhook`](../../src/app/api/stripe/webhook/route.ts)                                                                                                                               | 🚧     |
